## 🚀 Как использовать

### Установка:

1. **Загрузи расширение:**
   ```
   chrome://extensions → Developer mode → Load unpacked
   → Выбери папку hrhelper-linkedin-huntflow
   ```

2. **Настрой:**
   - Открой Extension options
   - Укажи Base URL: `http://localhost:8000`
   - Укажи API Token (получи из `/api/v1/accounts/users/token/`)
   - Выбери, какие системы использовать:
     - ✅ HR Helper (основное) - для сохранения ссылок
     - ✅ Huntflow (опционально) - для прямого сохранения кандидатов
   - Выбери, куда открывать: Huntflow / HR Helper / Спросить

3. **Готово!** Открой любой профиль в LinkedIn

- **API Token**: Токен для аутентификации

### Huntflow (опционально):

- **Huntflow**: Всегда открывать в Huntflow
- **HR Helper**: Всегда открывать в HR Helper
- **Спросить**: Показывать меню выбора

## 🔧 Backend API

### Существующие endpoints (работают как раньше):
- `GET /api/v1/huntflow/linkedin-applicants/status/` - проверка статуса
- `POST /api/v1/huntflow/linkedin-applicants/set-link/` - сохранение ссылки
- `POST /api/v1/linkedin/thread-mapping/` - сохранение thread mapping
- `GET /api/v1/linkedin/thread-mapping/` - получение thread mapping

### Новые endpoints (опционально, для двойной интеграции):
- `POST /api/v1/linkedin/candidates/` - сохранение кандидата в HRHelper
  - Принимает: `{ name, position, email, phone, linkedin_url, huntflow_id, huntflow_url }`
  - Возвращает: `{ id, url }`

## 🐛 Troubleshooting

### Кнопка не появляется
- Проверь API Token в настройках
- Проверь, что backend доступен
- Включи DEBUG в content.js: `DEBUG = true`

### Ошибка сохранения
- Проверь backend логи
- Проверь, что API Token правильный
- Проверь, что backend endpoint существует

### Huntflow не работает
- Убедись, что залогинен в huntflow.ru в браузере
- Проверь, что "Huntflow" включён в настройках
- Проверь консоль на ошибки CORS
