## Визуальное руководство по расширению

### 1. Страница профиля LinkedIn (`/in/username/`)

**Расположение виджета:** Рядом с кнопкой "More" (Ещё) в action bar профиля

```
┌─────────────────────────────────────────────────────────┐
│  [Photo]  John Doe                                      │
│           Software Engineer at Company                  │
│                                                          │
│  [Connect] [Message] [More ▼] [Huntflow] ← ЗДЕСЬ       │
└─────────────────────────────────────────────────────────┘
```

**Если кандидат есть в базе:**
```
[Huntflow] ← синяя кнопка, клик открывает карточку
```

**Если кандидата нет:**
```
[Ссылка на кандидата в Huntflow...        ] [Сохранить]
```

**Если кандидат есть в базе:**
```
╔═══════════════════════════════════════════════════╗
```

**Стили блока на /messaging/:**
- Фон: `#f3f6f8` (светло-серый)
- Padding: `12px 16px`
- Бордер снизу: `1px solid rgba(0,0,0,.08)`
- Инпут: `flex: 1` (растягивается на всю ширину)

### 3. Автоматический маппинг thread_id → profile_url

**Как это работает:**

1. **Пользователь открывает профиль** `https://www.linkedin.com/in/john-doe/`
   ```
   [HRHelper] Profile: john-doe
   [HRHelper] Found thread: 2-M2UxNjYx... ← извлекается из кнопки "Message"
   [HRHelper] Thread mapping saved
   ```

2. **Пользователь открывает сообщения** `https://www.linkedin.com/messaging/thread/2-M2UxNjYx.../`
   ```
   [HRHelper] Messaging page detected
   [HRHelper] Profile from cache: https://linkedin.com/in/john-doe/
   [HRHelper] Widget displayed above composer
   ```

3. **Виджет отображается автоматически** без дополнительных кликов

### 4. Состояния виджета

#### Состояние: "Открыть" (exists = true)
```
┌──────────────┐
│  Huntflow    │ ← Синяя кнопка (#0a66c2)
└──────────────┘
```
- Tooltip: "Открыть в Huntflow"
- Клик: открывает карточку кандидата в новой вкладке

#### Состояние: "Сохранить" (exists = false)
```
┌─────────────────────────────────────────┬──────────────┐
│ Ссылка на кандидата в Huntflow...       │  Сохранить   │
└─────────────────────────────────────────┴──────────────┘
```
- Placeholder: "Ссылка на кандидата в Huntflow"
- Клик "Сохранить": отправляет POST `/set-link/`
- После сохранения: переключается в состояние "Открыть"

#### Состояние: "Ошибка авторизации"
```
┌─────────────────────────────────────────┬──────────────┐
│ Нужна авторизация (проверь API Token)   │  Сохранить   │ (disabled)
└─────────────────────────────────────────┴──────────────┘
```
- Инпут disabled (opacity: 0.6)
- Кнопка disabled
- Tooltip: сообщение об ошибке

### 5. Производительность

**Throttling:**
- MutationObserver: срабатывает максимум раз в 3 секунды
- API запросы: максимум 1 status GET + 1 set-link POST на профиль
- Кэширование: 30 секунд для status GET

**DOM операции:**
- Виджет создаётся **один раз** при загрузке страницы
- Обновления через `display: block/none` (не пересоздаём элементы)
- Event listeners добавляются один раз (не дублируются)

**Результат:**
- ✅ Нет бесконечных циклов MutationObserver
- ✅ Нет множественных API запросов
- ✅ LinkedIn не блокирует/не тормозит
- ✅ Консоль чистая (без ошибок `chrome-extension://invalid/`)
