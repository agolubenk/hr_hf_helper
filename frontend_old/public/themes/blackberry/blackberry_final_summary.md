## 💡 Примеры Использования

### Сценарий: Application Review Process

```
1. Application Received
   → Orange button (view application)

2. In Review
   → Blackberry badge "In Review"
   → Blackberry button "Review Details"

3. Need More Info
   → Blackberry alert "Awaiting documents"
   → Form fields highlighted

4. Issues Found
   → Tomato alert "Please fix requirements"
   → Tomato button "Edit Application"

5. Approved
   → Rukkola checkmark "✓ Approved"
   → Green button "Send Welcome"

6. Hire
   → Orange action "Hire Candidate"
```

## 🔄 Переключение Между Темами

```javascript
// Переключение на Light Mode
document.documentElement.setAttribute('data-theme', 'blackberry-black-light');

// Переключение на Dark Mode
document.documentElement.setAttribute('data-theme', 'classic-energetic-blackberry-dark');

// С localStorage
localStorage.setItem('theme', 'blackberry-black-light');
```
