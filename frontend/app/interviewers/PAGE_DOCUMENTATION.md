# Документация страницы: Интервьюеры (interviewers/page.tsx)

## Общее описание

Страница управления интервьюерами компании. Позволяет добавлять, редактировать, удалять интервьюеров, управлять их активностью и просматривать календари.

## Компоненты страницы

### 1. Таблица интервьюеров
- **Компонент**: `Table` из Radix UI
- **Назначение**: Отображение списка всех интервьюеров
- **Колонки**:
  - Имя (ФИО)
  - Email
  - Статус (активен/неактивен через Switch)
  - Календарь (кнопка копирования ссылки, кнопка открытия)
  - Действия (редактирование, удаление)
- **Логика**: 
  - Фильтрация по `searchQuery`
  - Пагинация с настраиваемым размером страницы
  - Inline-редактирование при клике на кнопку редактирования
  - Обработка пустого состояния

### 2. Форма добавления интервьюера
- **Компонент**: Dialog с формой
- **Назначение**: Создание нового интервьюера
- **Поля**:
  - Имя (обязательное)
  - Фамилия (обязательное)
  - Отчество (опционально)
  - Email (обязательное)
  - Статус (активен/неактивен)
- **Логика**: 
  - Валидация обязательных полей
  - Отправка данных на сервер
  - Обновление списка после создания

## Состояние компонента

### State переменные:
- `interviewers`: массив всех интервьюеров
- `loading`: флаг загрузки данных
- `searchQuery`: поисковый запрос
- `currentPage`: текущая страница пагинации
- `pageSize`: размер страницы (10, 20, 50, 100)
- `totalCount`: общее количество интервьюеров
- `editingId`: ID интервьюера для редактирования (null если не редактируется)
- `showAddForm`: флаг отображения формы добавления
- `saving`: флаг сохранения

- **Логика**:

  - Обновляет состояние
- **Вызывается**: 
  - При монтировании компонента
  - При изменении `currentPage` или `pageSize`

## Фильтрация и поиск

### Поиск (searchQuery)
- **Поле**: TextField с иконкой поиска
- **Логика**: 
  - Ищет по имени, фамилии, отчеству, email
  - Без учета регистра
  - Debounce для уменьшения количества запросов
- **Поведение**: При вводе обновляется список интервьюеров

## Пагинация

- **Размер страницы**: Настраиваемый (10, 20, 50, 100 элементов)
- **Кнопки**: Первая, Предыдущая, Следующая, Последняя
- **Отображение**: "Страница X из Y"
- **Логика**: 
  - `currentPage` и `totalPages` вычисляются на основе `filteredInterviewers`
  - При переключении страницы обновляется отображаемый список
