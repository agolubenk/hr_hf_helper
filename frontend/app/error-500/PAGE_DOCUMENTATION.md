# Документация страницы: Ошибка 500 (error-500/page.tsx)

## Общее описание

Страница ошибки 500 (Internal Server Error). Отображается при внутренних ошибках сервера.

## Компоненты страницы

### 1. Сообщение об ошибке
- **Компонент**: `Text` с описанием
- **Назначение**: Информирование пользователя об ошибке
- **Логика**: 
  - Отображает код ошибки 500
  - Показывает сообщение "Внутренняя ошибка сервера"
  - Описание проблемы

### 2. Кнопка возврата
- **Компонент**: `Button` с навигацией
- **Назначение**: Возврат на главную страницу
- **Логика**: 
  - При клике происходит переход на `/`
  - Позволяет пользователю вернуться в приложение
- **Связи**: Навигация на `/`
