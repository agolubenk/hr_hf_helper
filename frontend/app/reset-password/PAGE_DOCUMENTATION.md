# Документация страницы: Сброс пароля (reset-password/page.tsx)

## Общее описание

Страница сброса пароля. Позволяет установить новый пароль после перехода по ссылке из email.

## Компоненты страницы

### 1. Форма сброса пароля
- **Компонент**: Форма с полями
- **Назначение**: Установка нового пароля
- **Поля**:
  - Новый пароль (обязательное)
  - Подтверждение пароля (обязательное)
- **Логика**: 
  - Валидация пароля (минимальная длина, сложность)
  - Проверка совпадения паролей
  - Отправка нового пароля на сервер
  - Показ сообщения об успехе

### 2. FloatingLabelInput
- **Расположение**: `@/components/FloatingLabelInput`
- **Назначение**: Поля ввода с плавающими метками
- **Используется**: Для полей нового пароля и подтверждения

## Состояние компонента

### State переменные:
- `password`: значение поля нового пароля
- `confirmPassword`: значение поля подтверждения пароля
- `token`: токен сброса пароля из URL
- `isLoading`: флаг загрузки
- `isSuccess`: флаг успешного сброса пароля

## Функции и обработчики

### handleSubmit(e)
- **Назначение**: Обработчик отправки формы сброса пароля
- **Логика**: 
  1. Предотвращает стандартное поведение формы
  2. Валидирует пароль (длина, сложность)
  3. Проверяет совпадение паролей
  4. Отправляет новый пароль и токен на сервер
  5. При успехе показывает сообщение и устанавливает `isSuccess = true`
  6. При ошибке показывает сообщение об ошибке

## URL параметры

### ?token=TOKEN
- **Тип**: Токен сброса пароля
- **Назначение**: Токен для сброса пароля из email
- **Пример**: `/reset-password?token=abc123` использует токен abc123
- **Обработка**: 
  - Читается через `useSearchParams()`
  - Используется для отправки запроса на сброс пароля
