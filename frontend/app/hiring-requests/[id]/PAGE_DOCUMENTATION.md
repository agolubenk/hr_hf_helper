# Документация страницы: Детальный просмотр заявки (hiring-requests/[id]/page.tsx)

## Общее описание

Страница детального просмотра заявки на подбор. Отображает полную информацию о заявке, позволяет редактировать и управлять заявкой.

## Компоненты страницы

### 1. Заголовок страницы
- **Компонент**: `Flex` с кнопкой "Назад"
- **Назначение**: Навигация и заголовок страницы
- **Логика**: 
  - Кнопка "Назад" возвращает на страницу списка заявок
  - Отображает название заявки
- **Связи**: Навигация на `/hiring-requests`

### 2. Информация о заявке
- **Компонент**: Карточки с информацией
- **Назначение**: Отображение детальной информации о заявке
- **Секции**:
  - Основная информация (название, грейд, проект, отдел)
  - Рекрутер и сроки
  - Статус и приоритет
  - Технологии
  - Кандидаты
  - SLA метрики

## URL параметры

### [id]
- **Тип**: Динамический параметр маршрута
- **Назначение**: ID заявки для просмотра
- **Пример**: `/hiring-requests/123` отображает заявку с ID 123
- **Обработка**: 
  - Читается через `useParams()`
  - Используется для загрузки данных заявки
