# Документация страницы: Workflow (workflow/page.tsx)

## Общее описание

Основная рабочая страница для работы рекрутера с кандидатами. Центральный хаб для общения с кандидатами, внесения данных, назначения интервью и управления процессом найма.

## Компоненты страницы

### 1. WorkflowHeader
- **Расположение**: `@/components/workflow/WorkflowHeader`
- **Назначение**: Заголовок страницы с управлением вакансией и настройками
- **Пропсы**:
  - `onSlotsClick`: обработчик клика на кнопку "слоты" (открытие/закрытие панели слотов)
  - `slotsOpen`: флаг открытости панели слотов
- **Логика**: 
  - Быстрые кнопки для коммуникации (Telegram, WhatsApp, Viber, LinkedIn, Email)
  - Тогглер типа процесса: Скрининг (30 мин) / Интервью (90 мин)
  - Выбор вакансии из выпадающего списка
  - Выбор офиса: Минск, Варшава, Гомель
  - Кнопки управления: Календарь, Вакансия, Свободные слоты, Обновить
  - Настройки интервью (только для типа "Интервью"):
    - Формат: Онлайн / Офис
    - Выбор интервьюеров (чекбоксы)
- **Связи**: 
  - Управляет открытием/закрытием `SlotsPanel`
  - Передает настройки в `WorkflowChat`

### 2. WorkflowChat
- **Расположение**: `@/components/workflow/WorkflowChat`
- **Назначение**: Чат-интерфейс для работы с кандидатами
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение истории сообщений (пользователь, система, инвайты)
  - Обработка команд через теги:
    - `#add`: добавление кандидата из файла резюме
    - `#hr_screening`: HR скрининг (ссылка Huntflow + текст ответов)
    - `#tech_screening`: технический скрининг (ссылка Huntflow + дата-время)
    - `#interview`: создание интервью (ссылка Huntflow + дата-время)
    - `#delete`: отмена последнего действия
  - Управление файлами: загрузка резюме
  - Управление инвайтами: создание, копирование, пересоздание scorecard
  - Управление отклонениями: выбор причины отказа
  - Скрытие сообщений
  - Автопрокрутка к новым сообщениям
- **Связи**: 
  - API: отправка команд на сервер для обработки
  - Huntflow: интеграция для синхронизации данных
  - Google Calendar: создание событий интервью

### 3. WorkflowSidebar
- **Расположение**: `@/components/workflow/WorkflowSidebar`
- **Назначение**: Боковая панель с информацией и быстрыми действиями
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Кнопка "Вики": открытие вики в новой вкладке
  - Отчеты последних недель:
    - Текущая неделя: статистика по этапам (раскрывающаяся секция)
    - Предыдущая неделя: статистика по этапам (раскрывающаяся секция)
  - Быстрые действия для коммуникации:
    - Telegram: несколько аккаунтов
    - WhatsApp: несколько номеров
    - Viber: несколько номеров
    - LinkedIn: несколько профилей
    - Email: несколько адресов
- **Связи**: 
  - `/wiki` - переход к вики
  - Внешние сервисы: открытие в новой вкладке

### 4. SlotsPanel
- **Расположение**: `@/components/workflow/SlotsPanel`
- **Назначение**: Панель свободных слотов для интервью
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Текущая неделя: отображение свободных слотов
  - Следующая неделя: отображение свободных слотов
  - Раскрытие/сворачивание секций недель
  - Карточки слотов: дата, день недели, список временных слотов, количество слотов
- **Связи**: 
  - Google Calendar: синхронизация слотов с календарем интервьюеров
  - WorkflowHeader: управление открытием/закрытием

## Состояние компонента

### State переменные:
- `slotsOpen`: флаг открытия/закрытия панели слотов

## Функции и обработчики

### useEffect для padding контента
- **Назначение**: Устанавливает специальный верхний padding для контента AppLayout
- **Логика**: 
  - Находит элемент контента через CSS селектор
  - Устанавливает `padding-top: 8px` для этой страницы
  - Сохраняет оригинальное значение для восстановления
  - Восстанавливает при размонтировании
- **Причина**: Workflow страница требует меньший верхний отступ для более компактного размещения

## Структура страницы

### Layout
- **AppLayout**: общий layout с Header и Sidebar
- **Специальный padding**: 8px сверху (устанавливается через useEffect)

### Основной контент
- **WorkflowHeader**: заголовок с управлением (фиксированный сверху)
- **SlotsPanel**: условно рендерится при `slotsOpen === true`
- **Две колонки**:
  - Левая: `WorkflowChat` (чат для работы с кандидатами)
  - Правая: `WorkflowSidebar` (информация о кандидате и быстрые действия)

## Команды чата

### #add
- **Назначение**: Добавление кандидата из файла резюме
- **Использование**: Прикрепить файл резюме и отправить сообщение с тегом `#add`
- **Результат**: Система обрабатывает резюме и добавляет кандидата в Huntflow

### #hr_screening
- **Назначение**: HR скрининг кандидата
- **Использование**: Отправить ссылку на кандидата в Huntflow + текст ответов на вопросы
- **Результат**: Система сохраняет данные и передает в Huntflow

### #tech_screening
- **Назначение**: Технический скрининг
- **Использование**: Отправить ссылку на кандидата в Huntflow + дата-время интервью
- **Результат**: Система создает инвайт и добавляет в календарь

### #interview
- **Назначение**: Создание интервью
- **Использование**: Отправить ссылку на кандидата в Huntflow + дата-время интервью
- **Результат**: Система создает инвайт, добавляет в календарь, создает scorecard

### #delete
- **Назначение**: Отмена последнего действия
- **Использование**: Отправить сообщение с тегом `#delete`
- **Результат**: Система отменяет последнее действие (удаление кандидата, записи или события)

## Интеграции

### Huntflow
- **Синхронизация данных**: Кандидаты, вакансии, статусы
- **Ссылки**: Формат `https://huntflow.ru/my/org#/vacancy/[id]/filter/[id]/id/[id]`

### Google Calendar
- **Создание событий**: При создании интервью через команды `#tech_screening` или `#interview`
- **Синхронизация слотов**: `SlotsPanel` получает свободные слоты из календарей интервьюеров

### Google Meet
- **Создание встреч**: Для онлайн интервью автоматически создается Google Meet ссылка

### Google Drive
- **Scorecard**: Создание и хранение scorecard файлов
