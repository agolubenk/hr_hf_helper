# Документация страницы: Ответы кандидатам (candidate-responses/page.tsx)

## Общее описание

Страница управления шаблонами ответов кандидатам. Позволяет создавать и управлять шаблонами ответов, привязанными к грейдам или общими, а также управлять слотами для быстрого копирования.

## Компоненты страницы

### 1. GeneralTemplatesTab
- **Расположение**: `@/components/candidate-responses/GeneralTemplatesTab`
- **Назначение**: Общие шаблоны ответов (не привязанные к грейдам)
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение списка общих шаблонов
  - Создание новых шаблонов
  - Редактирование существующих шаблонов
  - Удаление шаблонов
  - Копирование шаблонов
- **Связи**: 
  - API: загрузка и сохранение шаблонов
  - Используется для быстрого ответа кандидатам

### 2. GradeTemplatesTab
- **Расположение**: `@/components/candidate-responses/GradeTemplatesTab`
- **Назначение**: Шаблоны ответов, привязанные к конкретным грейдам
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение шаблонов, сгруппированных по грейдам
  - Создание шаблонов для конкретного грейда
  - Редактирование шаблонов
  - Удаление шаблонов
- **Связи**: 
  - API: загрузка и сохранение шаблонов
  - Использует грейды из настроек компании

### 3. SlotsTab
- **Расположение**: `@/components/candidate-responses/SlotsTab`
- **Назначение**: Управление слотами (шаблонами свободного времени)
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение списка слотов
  - Создание новых слотов
  - Редактирование слотов
  - Удаление слотов
  - Копирование слотов для быстрого использования
- **Связи**: 
  - API: загрузка и сохранение слотов
  - Используется в чате для быстрого копирования доступного времени

## Состояние компонента

### State переменные:
- `activeTab`: текущая активная вкладка ('general' | 'grades' | 'slots')

## Функции и обработчики

### handleTabChange(value)
- **Назначение**: Переключение между вкладками
- **Логика**: 
  - Обновляет `activeTab`
  - Обновляет URL параметр `?tab=` для синхронизации
- **Поведение**: 
  - Вызывается при клике на вкладку
  - Обновляет URL без прокрутки страницы
  - Позволяет делиться ссылками на конкретные вкладки

### useEffect для синхронизации с URL
- **Назначение**: Синхронизация активной вкладки с URL параметром
- **Логика**: 
  - Читает параметр `?tab=` из URL
  - Валидирует значение
  - Устанавливает `activeTab`
- **Поведение**: 
  - Выполняется при изменении `tabParam`
  - Позволяет открывать страницу с конкретной вкладкой через URL

## Вкладки

### 1. Общие шаблоны (activeTab === 'general')
- **Компонент**: `GeneralTemplatesTab`
- **Назначение**: Управление общими шаблонами ответов
- **Иконка**: `ChatBubbleIcon`
- **Функциональность**: 
  - Создание шаблонов для любых ситуаций
  - Не привязаны к конкретным грейдам
  - Используются для стандартных ответов

### 2. По грейдам (activeTab === 'grades')
- **Компонент**: `GradeTemplatesTab`
- **Назначение**: Управление шаблонами, привязанными к грейдам
- **Иконка**: `StarIcon`
- **Функциональность**: 
  - Шаблоны для конкретных грейдов (Junior, Middle, Senior и т.д.)
  - Разные шаблоны для разных уровней
  - Автоматический выбор шаблона по грейду кандидата

### 3. Слоты (activeTab === 'slots')
- **Компонент**: `SlotsTab`
- **Назначение**: Управление слотами (шаблонами свободного времени)
- **Иконка**: `CalendarIcon`
- **Функциональность**: 
  - Создание шаблонов доступного времени
  - Быстрое копирование для отправки кандидату
  - Управление расписанием

## URL параметры

### ?tab=general | ?tab=grades | ?tab=slots
- **Назначение**: Открытие конкретной вкладки при загрузке страницы
- **Логика**: 
  - Читается в `useEffect`
  - Валидируется перед установкой
  - Используется для глубоких ссылок
- **Пример**: `/candidate-responses?tab=grades` откроет вкладку "По грейдам"
