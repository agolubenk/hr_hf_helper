# Документация страницы: Профиль (profile/page.tsx)

## Общее описание

Страница профиля пользователя. Позволяет управлять личными данными, настраивать интеграции, управлять быстрыми кнопками и настраивать акцентный цвет темы.

## Компоненты страницы

### 1. UserCard
- **Расположение**: `@/components/profile/UserCard`
- **Назначение**: Карточка пользователя с основной информацией
- **Пропсы**: Данные пользователя (имя, email, роль и т.д.)
- **Логика**: Отображает основную информацию о пользователе
- **Связи**: Получает данные из API или localStorage

### 2. ProfileNavigation
- **Расположение**: `@/components/profile/ProfileNavigation`
- **Назначение**: Навигация между вкладками профиля
- **Пропсы**:
  - `activeTab`: текущая активная вкладка
  - `onTabChange`: обработчик изменения вкладки
- **Логика**: 
  - Отображает вкладки: Профиль, Редактирование, Интеграции и API, Быстрые кнопки
  - Подсвечивает активную вкладку
- **Связи**: Управляет переключением между вкладками

### 3. ProfileInfo
- **Расположение**: `@/components/profile/ProfileInfo`
- **Назначение**: Просмотр информации о пользователе (вкладка "Профиль")
- **Пропсы**: Данные пользователя
- **Логика**: Отображает информацию о пользователе в режиме только чтения
- **Связи**: Используется при `activeTab === 'profile'`

### 4. ProfileEditForm
- **Расположение**: `@/components/profile/ProfileEditForm`
- **Назначение**: Редактирование данных пользователя (вкладка "Редактирование")
- **Пропсы**: 
  - Данные пользователя
  - `onSave`: обработчик сохранения изменений
- **Логика**: 
  - Форма редактирования личных данных
  - Валидация полей
  - Сохранение через API
- **Связи**: Используется при `activeTab === 'edit'`

### 5. IntegrationsPage
- **Расположение**: `@/components/profile/IntegrationsPage`
- **Назначение**: Настройка интеграций и API (вкладка "Интеграции и API")
- **Пропсы**: Настройки интеграций
- **Логика**: 
  - Управление интеграциями (Huntflow, Google Calendar, и т.д.)
  - Настройка API ключей
  - Управление доступом
- **Связи**: Используется при `activeTab === 'integrations'`

### 6. QuickButtonsPage
- **Расположение**: `@/components/profile/QuickButtonsPage`
- **Назначение**: Управление быстрыми кнопками (вкладка "Быстрые кнопки")
- **Пропсы**: Список быстрых кнопок
- **Логика**: 
  - Добавление/удаление быстрых кнопок
  - Настройка ссылок и иконок
  - Упорядочивание кнопок
- **Связи**: Используется при `activeTab === 'quick-buttons'`

### 7. AccentColorSettings
- **Расположение**: `@/components/profile/AccentColorSettings`
- **Назначение**: Настройка акцентного цвета темы
- **Пропсы**: 
  - `lightThemeAccentColor`: акцентный цвет для светлой темы
  - `darkThemeAccentColor`: акцентный цвет для темной темы
  - `onLightThemeAccentColorChange`: обработчик изменения цвета светлой темы
  - `onDarkThemeAccentColorChange`: обработчик изменения цвета темной темы
- **Логика**: 
  - Выбор цвета через color picker
  - Применение цвета к теме через `useTheme`
- **Связи**: Использует `useTheme` из `ThemeProvider`

## Состояние компонента

### State переменные:
- `activeTab`: текущая активная вкладка ('profile' | 'edit' | 'integrations' | 'quick-buttons')

## Функции и обработчики

### getInitialTab()
- **Назначение**: Определение начальной активной вкладки
- **Логика**:
  1. Проверяет URL параметр `?tab=` (приоритет)
  2. Если параметр 'integrations' - возвращает 'integrations'
  3. Проверяет localStorage на наличие сохраненной вкладки
  4. Если сохраненная вкладка валидна - возвращает её
  5. По умолчанию возвращает 'profile'
- **Используется**: При инициализации компонента

### useEffect для синхронизации вкладки
- **Назначение**: Синхронизация активной вкладки между вкладками браузера
- **Логика**: 
  - Сохраняет активную вкладку в localStorage при изменении
  - Слушает события 'storage' для синхронизации между вкладками
  - Обновляет URL параметр `?tab=` при изменении вкладки
- **Поведение**: 
  - При изменении `activeTab` сохраняет в localStorage
  - При событии 'storage' обновляет `activeTab` из localStorage
  - При изменении вкладки обновляет URL без перезагрузки страницы

### 1. Профиль (activeTab === 'profile')
- **Компонент**: `ProfileInfo`
- **Назначение**: Просмотр информации о пользователе
- **Функциональность**: Отображение данных в режиме только чтения

### 2. Редактирование (activeTab === 'edit')
- **Компонент**: `ProfileEditForm`
- **Назначение**: Редактирование личных данных
- **Функциональность**:

### 3. Интеграции и API (activeTab === 'integrations')
- **Компонент**: `IntegrationsPage`

- **Функциональность**:

### 4. Быстрые кнопки (activeTab === 'quick-buttons')
- **Компонент**: `QuickButtonsPage`

## Настройка акцентного цвета

### AccentColorSettings
- **Расположение**: Отображается на всех вкладках (кроме настроек темы)
- **Логика**: 
  - Выбор цвета для светлой темы
  - Выбор цвета для темной темы
  - Применение через `useTheme.setLightThemeAccentColor()` и `setDarkThemeAccentColor()`
- **Связи**: Использует `useTheme` из `ThemeProvider`

## URL параметры

### ?tab=integrations
- **Назначение**: Открытие вкладки "Интеграции и API" при загрузке страницы
- **Логика**: 
  - Читается в `getInitialTab()`
  - Используется для перехода из Sidebar на "Интеграции и API"
- **Пример**: `/profile?tab=integrations`

## Синхронизация между вкладками браузера

### localStorage
- **Ключ**: `'profileActiveTab'`
- **Значение**: текущая активная вкладка
- **Логика**: 
  - Сохраняется при изменении `activeTab`
  - Читается при инициализации
  - Синхронизируется через события 'storage'

### События storage
- **Назначение**: Синхронизация активной вкладки между вкладками браузера
- **Логика**: 
  - Слушает события 'storage' в других вкладках
  - При изменении `profileActiveTab` в другой вкладке обновляет `activeTab`
  - Позволяет синхронизировать состояние между несколькими открытыми вкладками
