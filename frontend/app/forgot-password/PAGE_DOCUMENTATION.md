# Документация страницы: Восстановление пароля (forgot-password/page.tsx)

## Общее описание

Страница восстановления пароля. Позволяет запросить восстановление пароля через email.

## Компоненты страницы

### 1. Форма восстановления пароля
- **Компонент**: Форма с полем email
- **Назначение**: Запрос восстановления пароля
- **Поля**:
  - Email (обязательное)
- **Логика**: 
  - Валидация email
  - Отправка запроса на восстановление на сервер
  - Показ сообщения об успехе
- **TODO**: Реализовать реальную отправку запроса

### 2. FloatingLabelInput
- **Расположение**: `@/components/FloatingLabelInput`
- **Назначение**: Поле ввода с плавающей меткой
- **Пропсы**: 
  - `label`: текст метки
  - `type`: тип поля ('email')
  - `value`: значение поля
  - `onChange`: обработчик изменения
- **Логика**: Аналогична странице входа

## Состояние компонента

### State переменные:
- `email`: значение поля email
- `isLoading`: флаг загрузки (показывает индикатор при отправке)
- `isSubmitted`: флаг успешной отправки запроса

## Функции и обработчики

### handleSubmit(e)
- **Назначение**: Обработчик отправки формы восстановления пароля
- **Логика**: 
  1. Предотвращает стандартное поведение формы
  2. Валидирует email
  3. Отправляет запрос на восстановление на сервер
  4. При успехе показывает сообщение и устанавливает `isSubmitted = true`
  5. При ошибке показывает сообщение об ошибке
