# Документация страницы: Настройка Huntflow (huntflow/page.tsx)

## Общее описание

Страница настройки интеграции с Huntflow. Позволяет настроить маппинг данных между HR Helper и Huntflow для синхронизации.

## Состояние компонента

### State переменные:
- `orgMappings`: маппинг организаций (ключ - ID офиса HR Helper, значение - ID организации Huntflow)
- `stageMappings`: маппинг этапов (ключ - ID этапа HR Helper, значение - ID этапа Huntflow)
- `rejectionReasonMappings`: маппинг причин отказа
- `fieldMappings`: маппинг полей кандидатов
- `sourceMappings`: маппинг источников
