# Документация страницы: План найма (reporting/hiring-plan/page.tsx)

## Общее описание

Страница плана найма. Отображает планируемые наймы, статистику по планам и позволяет управлять планами найма.

## Компоненты страницы

### 1. Заголовок страницы
- **Компонент**: `Text` с названием
- **Назначение**: Заголовок страницы плана найма
- **Логика**: Отображает "План найма"

### 2. Статистика плана
- **Компонент**: Карточки с метриками
- **Назначение**: Отображение статистики по плану найма
- **Метрики**: 
  - Запланировано наймов
  - Выполнено наймов
  - В процессе
  - Просрочено
