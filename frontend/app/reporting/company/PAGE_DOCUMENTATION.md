# Документация страницы: Отчет по компании (reporting/company/page.tsx)

Страница детального отчета по компании. Отображает подробную аналитику по рекрутингу, метрики эффективности и статистику.

## Состояние компонента

### State переменные:
- `metrics`: данные метрик для отображения
- `loading`: флаг загрузки данных
- `dateRange`: выбранный период для отчета
