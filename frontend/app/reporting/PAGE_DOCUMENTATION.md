# Документация страницы: Отчетность (reporting/page.tsx)

## Общее описание

Главная страница отчетности. Отображает основные метрики и KPI по рекрутингу, предоставляет быстрый доступ к разделам отчетности.

## Компоненты страницы

### 1. Карточки метрик
- **Компонент**: `Card` из Radix UI
- **Назначение**: Отображение отдельных метрик
- **Структура**: 
  - Иконка метрики
  - Название метрики
  - Значение метрики
  - Изменение (если применимо)
- **Логика**: Отображает различные KPI в виде карточек

### 2. Быстрые ссылки
- **Компонент**: `Button` с навигацией
- **Назначение**: Быстрый переход к разделам отчетности
- **Ссылки**:
  - Отчет по компании
  - План найма
  - Связанные страницы (вакансии, заявки, интервьюеры)
- **Логика**: При клике происходит переход на соответствующую страницу

## Состояние компонента

### State переменные:
- Нет (все данные статические или вычисляемые)

## Функции и обработчики

### Вычисляемые метрики
- **HR метрики**: 
  - `totalInterviewers`: общее количество интервьюеров
  - `activeInterviewers`: количество активных интервьюеров
  - `totalRequests`: общее количество заявок
  - `plannedRequests`, `inProcessRequests`, `closedRequests`, `cancelledRequests`: заявки по статусам
  - `totalVacancies`, `activeVacancies`, `inactiveVacancies`: вакансии
- **SLA метрики**: 
  - `totalSLAs`: общее количество SLA
  - `activeSLAs`: количество активных SLA
  - `slaCoverage`: процент покрытия SLA
- **Скорость и исполнение**: 
  - `avgTimeToOffer`: среднее время до оффера (дни)
  - `avgTimeToHire`: среднее время до найма (дни)
  - `avgRecruiterDays`: средние дни работы рекрутера
  - `requestsOnTime`: заявки в срок
  - `requestsOverdue`: просроченные заявки
- **Результаты**: 
  - `totalCandidates`: общее количество кандидатов
  - `hiredCandidates`: нанятые кандидаты
  - `completionRate`: процент завершения

## Моковые данные

### metrics
Объект с метриками:
- HR метрики: интервьюеры, заявки, вакансии
- SLA метрики: покрытие SLA, активные SLA
- Скорость: среднее время до оффера, до найма
- Исполнение: заявки в срок, просроченные
- Результаты: кандидаты, нанятые, проценты
