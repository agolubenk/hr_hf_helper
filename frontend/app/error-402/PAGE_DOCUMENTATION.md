# Документация страницы: Ошибка 402 (error-402/page.tsx)

## Общее описание

Страница ошибки 402 (Payment Required). Отображается при необходимости оплаты подписки или при истечении подписки.

## Компоненты страницы

### 1. Сообщение об ошибке
- **Компонент**: `Text` с описанием
- **Назначение**: Информирование пользователя об ошибке
- **Логика**: 
  - Отображает код ошибки 402
  - Показывает сообщение "Требуется оплата"
  - Описание проблемы и инструкции

### 2. Кнопка оплаты
- **Компонент**: `Button` с навигацией
- **Назначение**: Переход на страницу оплаты
- **Логика**: 
  - При клике происходит переход на страницу оплаты
  - Позволяет пользователю оплатить подписку
