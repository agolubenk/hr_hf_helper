# Документация страницы: ИИ Чат (aichat/page.tsx)

## Общее описание

Страница ИИ чата для помощи в HR задачах. Позволяет общаться с ИИ ассистентом, управлять историей чатов, отправлять сообщения и прикреплять файлы.

## Компоненты страницы

### 1. ChatHistory
- **Расположение**: `@/components/aichat/ChatHistory`
- **Назначение**: Боковая панель с историей чатов
- **Пропсы**:
  - `chats`: массив всех чатов
  - `selectedChatId`: ID выбранного чата
  - `onChatSelect`: обработчик выбора чата
  - `onChatDelete`: обработчик удаления чата
  - `onChatRename`: обработчик переименования чата
  - `onNewChat`: обработчик создания нового чата
- **Логика**: 
  - Отображает список всех чатов
  - Показывает название и последнее сообщение каждого чата
  - Подсвечивает выбранный чат
  - Кнопки: переименование, удаление
  - Кнопка создания нового чата
- **Связи**: Управляет переключением между чатами

### 2. ChatHeader
- **Расположение**: `@/components/aichat/ChatHeader`
- **Назначение**: Заголовок чата с управлением
- **Пропсы**:
  - `chatTitle`: название чата
  - `onRename`: обработчик переименования чата
  - `onDelete`: обработчик удаления чата
- **Логика**: 
  - Отображает название чата
  - Кнопка переименования (открывает Dialog)
  - Кнопка удаления (показывает подтверждение через toast)
- **Связи**: Управляет текущим чатом

### 3. ChatMessages
- **Расположение**: `@/components/aichat/ChatMessages`
- **Назначение**: Отображение сообщений чата
- **Пропсы**:
  - `messages`: массив сообщений для отображения
  - `onScroll`: обработчик скролла (для определения позиции)
- **Логика**: 
  - Отображает сообщения пользователя и ИИ
  - Разные стили для сообщений пользователя и ИИ
  - Отображение прикрепленных файлов
  - Автоматическая прокрутка к последнему сообщению
- **Связи**: Отображает сообщения из `messages[currentChatId]`

### 4. ChatInput
- **Расположение**: `@/components/aichat/ChatInput`
- **Назначение**: Поле ввода с отправкой сообщений
- **Пропсы**:
  - `onSend`: обработчик отправки сообщения
  - `onFileAttach`: обработчик прикрепления файла
- **Логика**: 
  - TextArea для ввода сообщения
  - Кнопка прикрепления файла
  - Кнопка отправки сообщения
  - Поддержка отправки по Enter (Shift+Enter для новой строки)
- **Связи**: Отправляет сообщения в текущий чат

## Состояние компонента

### State переменные:
- `chats`: массив всех чатов пользователя
- `selectedChatId`: ID выбранного чата
- `messages`: объект сообщений по чатам (ключ - ID чата, значение - массив сообщений)
- `isAtBottom`: флаг, находится ли пользователь внизу списка сообщений

## Функции и обработчики

### Создание нового чата
- **Функция**: `handleNewChat()`
- **Логика**: 
  - Создает новый чат с названием "Чат DD.MM.YYYY HH:MM"
  - Добавляет в массив `chats`
  - Автоматически выбирает новый чат
  - Инициализирует пустой массив сообщений для нового чата
- **Поведение**: При создании нового чата он сразу становится активным

### Отправка сообщения
- **Функция**: `handleSendMessage(content, files?)`
- **Логика**: 
  - Создает сообщение пользователя с текущим временем
  - Добавляет в массив сообщений текущего чата
  - Отправляет на сервер для получения ответа ИИ
  - Добавляет ответ ИИ в массив сообщений

- **Функция**: `handleRenameChat(chatId, newTitle)`
- **Логика**: 
  - Обновляет название чата в массиве `chats`
  - Сохраняет через API

### Удаление чата
- **Функция**: `handleDeleteChat(chatId)`
- **Логика**:

  - Удаляет чат из массива `chats`
