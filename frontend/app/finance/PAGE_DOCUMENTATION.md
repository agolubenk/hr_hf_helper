# Документация страницы: Финансы (finance/page.tsx)

## Общее описание

Страница финансовых настроек компании. Управление грейдами, зарплатными вилками, курсами валют и налоговыми настройками.

## Компоненты страницы

### 1. GradesSection
- **Расположение**: `@/components/finance/GradesSection`
- **Назначение**: Настройка грейдов и уровней сотрудников
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение списка грейдов
  - Добавление новых грейдов
  - Редактирование существующих грейдов
  - Удаление грейдов
  - Настройка уровней внутри грейдов
- **Связи**: 
  - API: загрузка и сохранение грейдов
  - Используется для настройки зарплатных вилок

### 2. CurrencyRatesSection
- **Расположение**: `@/components/finance/CurrencyRatesSection`
- **Назначение**: Управление курсами валют
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение текущих курсов валют (USD, BYN, PLN, EUR)
  - Редактирование курсов валют
  - Автоматическое обновление курсов (TODO: реализовать)
  - История изменений курсов
- **Связи**: 
  - API: загрузка и сохранение курсов
  - Используется для расчета зарплатных вилок в разных валютах

### 3. TaxesSection
- **Расположение**: `@/components/finance/TaxesSection`
- **Назначение**: Настройка налогов
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Настройка налогов для разных стран
  - Особые настройки для PLN (Польша)
  - Расчет налогов для зарплатных вилок
- **Связи**: 
  - API: загрузка и сохранение налоговых настроек
  - Используется при расчете зарплатных вилок

## Состояние компонента

### State переменные:
- `activeTab`: текущая активная вкладка ('grades' | 'currencies' | 'taxes')

## Функции и обработчики

### handleTabChange(value)
- **Назначение**: Переключение между вкладками
- **Логика**: 
  - Обновляет `activeTab`
  - Обновляет URL параметр `?tab=` для синхронизации
- **Поведение**: 
  - Вызывается при клике на вкладку
  - Обновляет URL без прокрутки страницы
  - Позволяет делиться ссылками на конкретные вкладки

### useEffect для синхронизации с URL
- **Назначение**: Синхронизация активной вкладки с URL параметром
- **Логика**: 
  - Читает параметр `?tab=` из URL
  - Валидирует значение
  - Устанавливает `activeTab`
- **Поведение**: 
  - Выполняется при изменении `tabParam`
  - Позволяет открывать страницу с конкретной вкладкой через URL

## Вкладки

### 1. Грейды (activeTab === 'grades')
- **Компонент**: `GradesSection`
- **Назначение**: Настройка грейдов и уровней
- **Иконка**: `StarIcon`
- **Функциональность**: 
  - Управление грейдами (Junior, Middle, Senior и т.д.)
  - Настройка уровней внутри грейдов
  - Связь с зарплатными вилками

### 2. Курсы валют (activeTab === 'currencies')
- **Компонент**: `CurrencyRatesSection`
- **Назначение**: Управление курсами валют
- **Иконка**: `ReloadIcon`
- **Функциональность**: 
  - Редактирование курсов USD, BYN, PLN, EUR
  - Автоматическое обновление (TODO)
  - История изменений

### 3. Налоги (activeTab === 'taxes')
- **Компонент**: `TaxesSection`
- **Назначение**: Настройка налогов
- **Иконка**: `MixerHorizontalIcon`
- **Функциональность**: 
  - Настройка налогов для разных стран
  - Особые настройки для PLN
  - Расчет налогов

## URL параметры

### ?tab=grades | ?tab=currencies | ?tab=taxes
- **Назначение**: Открытие конкретной вкладки при загрузке страницы
- **Логика**: 
  - Читается в `useEffect`
  - Валидируется перед установкой
  - Используется для глубоких ссылок
- **Пример**: `/finance?tab=currencies` откроет вкладку "Курсы валют"
