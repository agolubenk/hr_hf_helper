# Документация страницы: Календарь (calendar/page.tsx)

## Общее описание

Страница календаря событий. Отображает интервью, скрининги и встречи, синхронизируется с Google Calendar, позволяет управлять событиями и слотами.

## Компоненты страницы

### 1. SlotsPanel
- **Расположение**: `@/components/workflow/SlotsPanel`
- **Назначение**: Панель свободных слотов для интервью
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: Отображение свободных слотов по неделям
- **Связи**: Синхронизируется с Google Calendar

### 2. Календарь (месячный вид)
- **Компонент**: Кастомная сетка дней месяца
- **Назначение**: Отображение событий в календарном виде
- **Логика**: 
  - Сетка дней текущего месяца
  - Отображение событий в днях
  - Навигация по месяцам (предыдущий/следующий)
  - Выделение текущего дня
- **Связи**: Использует данные из `mockEvents`

### 3. Таблица событий (недельный/дневной вид)
- **Компонент**: `Table` из Radix UI
- **Назначение**: Отображение событий в табличном виде
- **Колонки**:
  - Дата и время
  - Название события
  - Кандидат
  - Вакансия
  - Формат (Онлайн/Офис)
  - Участники
  - Действия
- **Логика**: 
  - Фильтрация по выбранному периоду
  - Сортировка по дате и времени
- **Связи**: Использует данные из `mockEvents`

### 4. Модальное окно детального просмотра события
- **Компонент**: `Dialog` из Radix UI
- **Назначение**: Просмотр детальной информации о событии
- **Логика**: 
  - Отображение всех данных события
  - Список участников с их статусами
  - Ссылки на Google Meet и Google Calendar
  - Кнопка копирования ссылки
- **Связи**: Открывается при клике на событие

## Состояние компонента

### State переменные:
- `viewMode`: режим отображения ('month' | 'week' | 'day' | 'list')
- `currentDate`: текущая дата для отображения
- `selectedOffice`: выбранный офис для фильтрации ('all' | 'minsk' | 'warsaw' | 'gomel')
- `searchQuery`: поисковый запрос
- `selectedEvent`: выбранное событие для детального просмотра
- `slotsOpen`: флаг открытия панели слотов

## Функции и обработчики

### Фильтрация событий
- **Логика**:
  1. Поиск: название, кандидат или вакансия содержит `searchQuery`
  2. Офис: совпадает с `selectedOffice` (или 'all')
  3. Период: событие попадает в выбранный период (месяц/неделя/день)
- **Результат**: `filteredEvents` - отфильтрованный массив событий

### Навигация по календарю
- **Предыдущий месяц/неделя/день**: Уменьшает `currentDate`
- **Следующий месяц/неделя/день**: Увеличивает `currentDate`
- **Сегодня**: Устанавливает `currentDate` на текущую дату

### Синхронизация с Google Calendar
- **Функция**: `handleSyncCalendar()`
- **Логика**: 
  - Отправляет запрос на синхронизацию
  - Обновляет события из Google Calendar
  - Показывает toast об успехе/ошибке

## Режимы отображения

### Месяц (viewMode === 'month')
- **Компонент**: Сетка дней месяца
- **Особенности**: 
  - Отображение всех дней месяца
  - События в днях
  - Навигация по месяцам

### Неделя (viewMode === 'week')
- **Компонент**: Таблица событий
- **Особенности**: 
  - События текущей недели
  - Навигация по неделям

### День (viewMode === 'day')
- **Компонент**: Таблица событий
- **Особенности**: 
  - События выбранного дня
  - Навигация по дням

### Список (viewMode === 'list')
- **Компонент**: Таблица событий
- **Особенности**: 
  - Все события с поиском и фильтрацией
  - Сортировка по дате

## Моковые данные

### mockEvents
Массив объектов событий с полями:
- `id`: уникальный идентификатор
- `title`: название события
- `start`: дата и время начала (ISO строка)
- `end`: дата и время окончания (ISO строка)
- `candidate`: имя кандидата
- `vacancy`: название вакансии
- `format`: 'online' | 'office'
- `location`: локация (для офисных событий)
- `googleMeetUrl`: ссылка на Google Meet (для онлайн)
- `googleCalendarUrl`: ссылка на событие в Google Calendar
- `attendees`: массив участников
- `office`: офис ('minsk' | 'warsaw' | 'gomel')
