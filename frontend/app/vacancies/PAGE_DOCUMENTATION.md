# Документация страницы: Вакансии (vacancies/page.tsx)

## Общее описание

Страница управления вакансиями компании. Позволяет просматривать, фильтровать, создавать и редактировать вакансии в двух режимах отображения: карточки и список.

## Компоненты страницы

### 1. VacanciesSearchFilters
- **Расположение**: `@/components/vacancies/VacanciesSearchFilters`
- **Назначение**: Поиск и фильтры для вакансий
- **Пропсы**:
  - `searchQuery`: текущий поисковый запрос
  - `onSearchChange`: обработчик изменения поиска
  - `selectedRecruiter`: выбранный рекрутер ('all' или имя)
  - `onRecruiterChange`: обработчик изменения рекрутера
  - `selectedStatus`: выбранный статус ('all' | 'active' | 'inactive')
  - `onStatusChange`: обработчик изменения статуса
- **Логика**: 
  - Поле поиска по названию или ID
  - Фильтр по рекрутеру (выпадающий список)
  - Фильтр по статусу (выпадающий список)
  - Кнопка "Поиск" (TODO: реализовать функциональность)
- **Связи**: Передает изменения фильтров в родительский компонент

### 2. VacanciesStats
- **Расположение**: `@/components/vacancies/VacanciesStats`
- **Назначение**: Статистика по вакансиям
- **Пропсы**:
  - `total`: общее количество вакансий
  - `active`: количество активных вакансий
  - `inactive`: количество неактивных вакансий
- **Логика**: Отображает 3 карточки со статистикой
- **Связи**: Получает данные из вычисленных значений на основе `mockVacancies`

### 3. VacancyCard
- **Расположение**: `@/components/vacancies/VacancyCard`
- **Назначение**: Карточка вакансии (режим "Карточки")
- **Пропсы**:
  - `vacancy`: объект вакансии
  - `onClick`: обработчик клика на карточку (просмотр)
  - `onEditClick`: обработчик клика на кнопку редактирования
  - `onStatusClick`: обработчик клика на статус (переключение)
- **Логика**: 
  - Отображает название, ID, рекрутера, локации, интервьюеров
  - Показывает предупреждения (если есть)
  - Кнопки действий: редактирование, просмотр
  - Кликабельный статус для быстрого переключения
- **Связи**: Используется только в режиме `viewMode === 'cards'`

### 4. VacancyListItem
- **Расположение**: `@/components/vacancies/VacancyListItem`
- **Назначение**: Элемент списка вакансии (режим "Список")
- **Пропсы**: Те же, что у `VacancyCard`
- **Логика**: 
  - Горизонтальное расположение информации
  - Компактное отображение всех данных в одной строке
- **Связи**: Используется только в режиме `viewMode === 'list'`

### 5. VacancyEditModal
- **Расположение**: `@/components/vacancies/VacancyEditModal`
- **Назначение**: Модальное окно просмотра/редактирования вакансии
- **Пропсы**:
  - `open`: флаг открытости
  - `onOpenChange`: обработчик изменения открытости
  - `vacancyId`: ID вакансии
  - `mode`: 'view' | 'edit'
  - `vacancy`: объект вакансии
  - `vacancyStatus`: текущий статус
  - `onVacancyStatusChange`: обработчик изменения статуса
  - `onSwitchToEdit`: переключение в режим редактирования
  - `vacancyTitle`: название для заголовка
- **Логика**: 
  - Режим просмотра: только чтение данных
  - Режим редактирования: возможность изменения всех полей
  - Управление статусом вакансии
- **Связи**: Открывается при клике на вакансию или кнопку редактирования

## Состояние компонента

### State переменные:
- `viewMode`: режим отображения ('cards' | 'list')
- `searchQuery`: поисковый запрос
- `selectedRecruiter`: выбранный рекрутер ('all' или имя)
- `selectedStatus`: выбранный статус ('all' | 'active' | 'inactive')
- `viewVacancyId`: ID вакансии для просмотра (открывает модальное окно)
- `editVacancyId`: ID вакансии для редактирования (открывает модальное окно)
- `statusOverrides`: объект переопределений статусов (для временных изменений без сохранения)

## Функции и обработчики

### getStatus(v)
- **Назначение**: Получение актуального статуса вакансии
- **Логика**: 
  - Проверяет наличие переопределения в `statusOverrides`
  - Если есть - возвращает переопределение, иначе оригинальный статус
- **Используется**: Для отображения актуального статуса с учетом временных изменений

### useEffect для URL параметра ?edit
- **Назначение**: Открытие модального окна редактирования через URL
- **Логика**: 
  - Читает параметр `edit` из URL
  - Если валиден - открывает модальное окно редактирования
- **Пример**: `/vacancies?edit=123` открывает редактирование вакансии с ID 123

## Фильтрация и поиск

### Поиск (searchQuery)
- **Поле**: TextField в `VacanciesSearchFilters`
- **Логика**: 
  - Ищет по названию вакансии (без учета регистра)
  - Ищет по ID вакансии (точное совпадение в строке)
- **Поведение**: Фильтрация происходит в реальном времени

### Фильтр по рекрутеру (selectedRecruiter)
- **Поле**: Select в `VacanciesSearchFilters`
- **Опции**: "Все рекрутеры", список рекрутеров
- **Логика**: Фильтрует по точному совпадению имени рекрутера
- **TODO**: Загружать список рекрутеров из API

### Фильтр по статусу (selectedStatus)
- **Поле**: Select в `VacanciesSearchFilters`
- **Опции**: "Все", "Активные", "Неактивные"
- **Логика**: Фильтрует по статусу (с учетом переопределений из `statusOverrides`)

## Режимы отображения

### Режим "Карточки" (viewMode === 'cards')
- **Компонент**: `VacancyCard`
- **Расположение**: Сетка карточек (`.cardsGrid`)
- **Особенности**: Вертикальное расположение информации, больше места для деталей

### Режим "Список" (viewMode === 'list')
- **Компонент**: `VacancyListItem`
- **Расположение**: Вертикальный список (`.listContainer`)
- **Особенности**: Горизонтальное расположение, компактное отображение

### Переключатель режимов
- **Компонент**: Две кнопки с иконками `GridIcon` и `ListBulletIcon`
- **Логика**: При клике меняет `viewMode` и перерисовывает список

## Управление статусами

### Переопределение статусов (statusOverrides)
- **Назначение**: Временное изменение статуса без сохранения на сервер
- **Структура**: `Record<number, 'active' | 'inactive'>` (ключ - ID вакансии, значение - новый статус)
- **Логика**: 
  - При клике на статус в карточке/списке обновляется `statusOverrides`
  - `getStatus()` учитывает переопределения при отображении
  - Позволяет быстро переключать статусы без немедленного сохранения

## Моковые данные

### mockVacancies
Массив объектов вакансий с полями:
- `id`: уникальный идентификатор
- `title`: название вакансии
- `status`: 'active' | 'inactive'
- `recruiter`: имя рекрутера
- `locations`: массив локаций
- `interviewers`: количество интервьюеров
- `date`: дата создания/обновления (может быть null)
- `hasWarning`: флаг наличия предупреждения
- `warningText`: текст предупреждения (опционально)

## Вычисляемые значения

### Статистика
- `totalVacancies`: `mockVacancies.length`
- `activeVacancies`: количество вакансий со статусом 'active' (с учетом переопределений)
- `inactiveVacancies`: количество вакансий со статусом 'inactive' (с учетом переопределений)

### filteredVacancies
Отфильтрованный список вакансий по трем условиям:
1. Поиск: название или ID содержит `searchQuery`
2. Рекрутер: совпадает с `selectedRecruiter` (или 'all')
3. Статус: совпадает с `selectedStatus` (или 'all', с учетом переопределений)

## Модальное окно редактирования

### Открытие
- При клике на вакансию: открывается в режиме просмотра (`viewVacancyId`)
- При клике на кнопку редактирования: открывается в режиме редактирования (`editVacancyId`)
- Через URL параметр `?edit=123`: открывается в режиме редактирования

### Закрытие
- При закрытии очищаются `viewVacancyId` и `editVacancyId`
- Можно переключиться из просмотра в редактирование через `onSwitchToEdit`
