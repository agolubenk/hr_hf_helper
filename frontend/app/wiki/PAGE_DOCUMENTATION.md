# Документация страницы: Вики (wiki/page.tsx)

## Общее описание

Главная страница вики (базы знаний). Отображает список статей, позволяет фильтровать по тегам и поисковому запросу, группирует статьи по категориям.

## Компоненты страницы

### 1. WikiHeader
- **Расположение**: `@/components/wiki/WikiHeader`
- **Назначение**: Заголовок страницы с кнопкой создания новой статьи
- **Пропсы**: 
  - `onCreateClick`: обработчик клика на кнопку создания
- **Логика**: 
  - Отображает заголовок "Вики"
  - Кнопка "Создать статью" для создания новой статьи
- **Связи**: При клике на кнопку открывает форму создания статьи

### 2. WikiFilters
- **Расположение**: `@/components/wiki/WikiFilters`
- **Назначение**: Фильтры и поиск для статей вики
- **Пропсы**:
  - `selectedTag`: выбранный тег для фильтрации (null - все теги)
  - `onTagChange`: обработчик изменения тега
  - `searchQuery`: текущий поисковый запрос
  - `onSearchChange`: обработчик изменения поиска
- **Логика**: 
  - Фильтр по тегам: отображает все уникальные теги из статей
  - Поиск: поле ввода для поиска по названию и описанию
- **Связи**: Управляет фильтрацией статей

### 3. WikiCategory
- **Расположение**: `@/components/wiki/WikiCategory`
- **Назначение**: Отображение категории со статьями
- **Пропсы**:
  - `category`: название категории
  - `pages`: массив статей в этой категории
- **Логика**: 
  - Отображает название категории
  - Рендерит список статей в категории через `WikiCard`
- **Связи**: Используется для группировки статей по категориям

### 4. WikiCard
- **Расположение**: `@/components/wiki/WikiCard`
- **Назначение**: Карточка статьи вики
- **Пропсы**:
  - `page`: объект статьи вики
  - `onClick`: обработчик клика (переход на детальную страницу)
- **Логика**: 
  - Отображает название, описание, теги и дату статьи
  - Кликабельная для перехода на детальную страницу
- **Связи**: При клике переходит на `/wiki/[id]`

## Состояние компонента

### State переменные:
- `selectedTag`: выбранный тег для фильтрации (null - все теги)
- `searchQuery`: поисковый запрос для фильтрации статей

## Функции и обработчики

### Фильтрация статей
- **Логика**:
  1. Фильтр по тегу: если `selectedTag` не null, фильтрует статьи, содержащие этот тег
  2. Поиск: если `searchQuery` не пустой, ищет по названию (`title`) и описанию (`description`) без учета регистра
  3. Оба условия применяются одновременно (логическое И)
- **Результат**: `filteredPages` - отфильтрованный массив статей

### Группировка по категориям
- **Логика**:
  1. Группирует отфильтрованные статьи по полю `category`
  2. Создает объект, где ключ - название категории, значение - массив статей
- **Структура**: `Record<string, WikiPage[]>` (ключ - название категории)

### Сортировка категорий
- **Логика**:
  1. Категория "Архитектура" всегда первая
  2. Остальные категории сортируются по алфавиту
- **Результат**: Отсортированный массив названий категорий для отображения

## Моковые данные

### wikiPages
Массив объектов статей вики с полями:
- `id`: уникальный идентификатор статьи
- `title`: название статьи
- `description`: краткое описание статьи
- `tags`: массив тегов статьи (с префиксом #, например, ['#настройка', '#финансы'])
- `date`: дата создания или последнего обновления (формат DD.MM.YYYY)
- `category`: категория статьи (например, 'Архитектура', 'Настройка')

## Фильтрация и поиск

### Фильтр по тегам (selectedTag)
- **Поле**: Список тегов в `WikiFilters`
- **Логика**: 
  - Извлекает все уникальные теги из всех статей
  - При выборе тега фильтрует статьи, содержащие этот тег
  - `null` означает "все теги" (без фильтрации)
- **Поведение**: При выборе тега обновляется список статей

### Поиск (searchQuery)
- **Поле**: TextField в `WikiFilters`
- **Логика**: 
  - Ищет по названию статьи (`title`) без учета регистра
  - Ищет по описанию статьи (`description`) без учета регистра
  - Применяется одновременно с фильтром по тегам
- **Поведение**: Фильтрация происходит в реальном времени при вводе

## Группировка и отображение

### Группировка по категориям
- **Логика**: 
  - Все отфильтрованные статьи группируются по полю `category`
  - Каждая категория отображается отдельным блоком через `WikiCategory`
  - Внутри категории статьи отображаются через `WikiCard`

### Сортировка категорий
- **Правило**: 
  - Категория "Архитектура" всегда первая
  - Остальные категории сортируются по алфавиту
- **Реализация**: 
  ```typescript
  const sortedCategories = Object.keys(groupedPages).sort((a, b) => {
    if (a === 'Архитектура') return -1
    if (b === 'Архитектура') return 1
    return a.localeCompare(b)
  })
  ```
