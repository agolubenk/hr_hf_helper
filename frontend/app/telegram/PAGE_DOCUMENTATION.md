# Полная документация модуля Telegram интеграции

## Общее описание

Модуль Telegram интеграции (`frontend/app/telegram`) предоставляет полный функционал для работы с Telegram аккаунтом в рамках HR Helper приложения. Модуль включает страницы входа, настройки двухфакторной аутентификации и управления чатами с расширенными возможностями.

## Структура модуля

```
frontend/app/telegram/
├── page.tsx                    # Главная страница входа в Telegram (QR-код и вход по номеру)
├── 2fa/
│   ├── page.tsx               # Страница настройки двухфакторной аутентификации
│   └── PAGE_DOCUMENTATION.md  # Документация страницы 2FA
├── chats/
│   ├── page.tsx               # Главная страница управления чатами (самый сложный компонент)
│   └── PAGE_DOCUMENTATION.md  # Документация страницы чатов
├── telegram.module.css        # Общие стили для всех страниц Telegram
└── PAGE_DOCUMENTATION.md      # Этот файл - общая документация модуля
```

## Компоненты модуля

### 1. Главная страница входа (`/telegram/page.tsx`)

**Назначение:** Страница для подключения Telegram аккаунта к HR Helper через QR-код или вход по номеру телефона.

**Основной функционал:**
- Генерация и отображение QR-кода для сканирования в приложении Telegram
- Форма входа по номеру телефона (альтернативный способ подключения)
- Валидация номера телефона (только цифры, скобки и знак +)

**Технические детали:**
- Использует детерминированный паттерн QR-кода (21×21 ячеек)
- Реализует finder pattern (углы 7×7) и timing pattern
- Поддерживает ввод номера телефона с форматированием

### 3. Страница управления чатами (`/telegram/chats/page.tsx`)

**Назначение:** Полнофункциональная страница для управления чатами Telegram, включая просмотр переписки, отправку сообщений, настройки чатов и аккаунта, управление папками и исключениями уведомлений.

**Это самый сложный и функциональный компонент модуля, содержащий более 3900 строк кода.**

#### 3.1. Основные возможности

**Управление чатами:**
- Отображение списка всех чатов с аватарами, названиями и превью сообщений
- Поиск чатов по названию в реальном времени
- Фильтрация по папкам
- Переключение между типами чатов (Чаты / Каналы и группы)
- Выбор и просмотр конкретного чата
- Отображение непрочитанных сообщений (Badge)

**Просмотр и отправка сообщений:**
- Просмотр истории переписки в выбранном чате
- Отправка сообщений с поддержкой форматирования (Rich Text Input)
- Прикрепление файлов к сообщениям
- Автоматическая прокрутка к последнему сообщению
- Кнопка прокрутки к последнему сообщению при скролле вверх
- Отображение авторов сообщений в группах
- Поддержка подгрупп для групп с переключением между ними

**Форматирование сообщений:**
- Поддержка Markdown-подобного форматирования (жирный, курсив, подчеркивание, зачеркивание)
- Отображение ссылок с превью
- Цитаты с полупрозрачным фоном
- Код-блоки с кнопкой копирования
- Визуальное форматирование в поле ввода (Rich Text Input)

**Настройки чатов:**
- Модальное окно настроек для каждого чата
- Редактирование информации о контакте (имя, фамилия, телефон, username)
- Управление заметками
- Включение/отключение автоматических ответов
- Блокировка/разблокировка контактов
- Удаление контактов
- Загрузка и просмотр изображений чатов (карусель)
- Установка главного изображения

**Настройки аккаунта:**
- Просмотр и редактирование информации профиля
- Загрузка и управление изображениями профиля (карусель)
- Установка главного изображения профиля
- Настройки уведомлений и звуков
- Управление исключениями уведомлений для разных типов чатов

**Управление папками:**
- Создание и удаление папок для организации чатов
- Редактирование названий папок
- Перетаскивание папок для изменения порядка (drag-and-drop)
- Отображение количества чатов в каждой папке
- Папка "Все" для просмотра всех чатов

**Исключения уведомлений:**
- Управление исключениями для личных чатов, групп и каналов
- Добавление/удаление чатов из исключений
- Поиск чатов в модальном окне исключений
- Отображение количества исключений

**Адаптивность:**
- Адаптивная верстка для мобильных устройств
- Мобильное меню для списка чатов
- Полноэкранный режим списка чатов на мобильных
- Автоматическое закрытие мобильного меню при выборе чата

#### 3.2. Техническая архитектура

**Состояние компонента:**

```typescript
// Основное состояние
- chats: TelegramChat[]                    // Массив всех чатов
- selectedChatId: string | null             // ID выбранного чата
- searchQuery: string                       // Поисковый запрос
- viewType: 'chats' | 'channels'           // Тип отображаемых чатов
- selectedFolderId: string | null          // ID выбранной папки
- folders: Folder[]                         // Массив папок

// Состояние UI
- mobileChatListOpen: boolean               // Открыт ли мобильный список чатов
- chatSettingsOpen: boolean                 // Открыто ли модальное окно настроек чата
- accountSettingsOpen: boolean              // Открыто ли модальное окно настроек аккаунта
- foldersSettingsOpen: boolean              // Открыто ли модальное окно папок
- exceptionsModalOpen: boolean              // Открыто ли модальное окно исключений

// Состояние сообщений
- message: string                           // Текст сообщения в поле ввода
- attachedFiles: AttachedFile[]             // Прикрепленные файлы
- showScrollToBottom: boolean                // Показать ли кнопку прокрутки вниз

// Состояние настроек чата
- settingsChatId: string | null             // ID чата для настроек
- autoReplyEnabled: boolean                 // Включены ли автоответы
- chatNote: string                          // Заметка к чату
- isEditingContact: boolean                 // Редактируется ли контакт
- isEditingNote: boolean                   // Редактируется ли заметка

// Состояние редактирования полей
- editName, editLastName, editPhone, etc.   // Поля редактирования контакта
- editingField: 'name' | 'lastName' | ...   // Какое поле редактируется
- editingAccountField: 'name' | 'username'  // Какое поле аккаунта редактируется

// Состояние изображений
- accountImages: string[]                    // Изображения профиля
- mainAccountImageIndex: number              // Индекс главного изображения профиля
- currentAccountImageIndex: number           // Текущий индекс в карусели профиля
- chatImages: Record<string, string[]>       // Изображения чатов (по ID чата)
- currentChatImageIndex: number              // Текущий индекс в карусели чата

// Состояние групп
- selectedSubChatId: string | null          // ID выбранной подгруппы

// Состояние уведомлений
- notificationsAllAccounts: boolean          // Включены ли уведомления
- notificationsSound: boolean               // Включены ли звуки
- notificationsPrivateChats: boolean        // Уведомления для личных чатов
- notificationsGroups: boolean              // Уведомления для групп
- notificationsChannels: boolean           // Уведомления для каналов
- notificationExceptions: {                  // Исключения уведомлений
    private: string[]
    groups: string[]
    channels: string[]
  }
```

**Ключевые функции:**

1. **handleChatClick(chatId)** - Выбор чата для просмотра
2. **handleSendMessage()** - Отправка сообщения в чат
3. **handleChatSettingsClick(chatId, e)** - Открытие настроек чата
4. **handleSaveContact()** - Сохранение изменений контакта
5. **handleBlockContact()** - Блокировка контакта
6. **handleUnblockContact()** - Разблокировка контакта
7. **handleDeleteContact()** - Удаление контакта
8. **handleCreateFolder()** - Создание новой папки
9. **handleDeleteFolder(folderId)** - Удаление папки
10. **handleDragEnd(event)** - Обработка перетаскивания папок
11. **handleAccountImageUpload()** - Загрузка изображения профиля
12. **handleChatImageUpload(chatId)** - Загрузка изображения чата
13. **handleAddException(chatId)** - Добавление чата в исключения
14. **handleRemoveException(chatId)** - Удаление чата из исключений

**Интерфейсы данных:**

```typescript
interface TelegramMessage {
  id: string
  text: string
  timestamp: string
  sender: 'user' | 'telegram'
  senderName?: string
  file?: { name: string; type: string; size: number }
  subChatId?: string  // ID подгруппы для групп
}

interface TelegramChat {
  id: string
  name: string
  preview: string
  avatar: string
  date: string
  unreadCount?: number
  messages?: TelegramMessage[]
  folderId?: string
  type: 'chat' | 'channel' | 'group'
  username?: string
  nickname?: string
  about?: string
  note?: string
  link?: string
  filesCount?: number
  autoReplyEnabled?: boolean
  status?: string
  isBlocked?: boolean
  lastName?: string
  phone?: string
  subChats?: Array<{ id: string; name: string }>  // Подгруппы для групп
}

interface Folder {
  id: string
  name: string
  icon?: 'briefcase' | 'folder' | 'person' | 'box' | 'star' | 'archive' | 'users' | 'project' | 'urgent'
}

interface AttachedFile {
  id: string
  name: string
  type: string
  size: number
}
```

#### 3.4. Особенности реализации

**Rich Text Input:**
- Визуальное отображение форматирования (не Markdown синтаксис)
- Горячие клавиши: Ctrl+B (жирный), Ctrl+I (курсив), Ctrl+U (подчеркивание), Ctrl+Shift+X (зачеркивание), Ctrl+Shift+. (цитата), Ctrl+K (ссылка)
- Shift+Enter для новой строки, Enter для отправки
- Тултип для вставки ссылок с возможностью редактирования текста ссылки
- Сохранение позиции курсора при форматировании

**Форматирование сообщений:**
- Поддержка жирного, курсивного, подчеркнутого, зачеркнутого текста
- Ссылки с превью (домен, полный URL, открытие в новой вкладке)
- Цитаты с полупрозрачным фоном и пунктирной левой границей
- Код-блоки с кнопкой копирования
- Заголовки (только для сообщений пользователя, не для Telegram)

**Группы и подгруппы:**
- Поддержка групп с вложенными подгруппами
- Скролл-меню для переключения между подгруппами
- Вариант "Единый чат" для просмотра всех сообщений группы
- Отображение авторов сообщений в группах (кроме сообщений пользователя)
- Фильтрация сообщений по выбранной подгруппе

**Управление изображениями:**
- Загрузка изображений профиля и чатов
- Карусель для просмотра всех загруженных изображений
- Установка главного изображения
- Отображение главного изображения в аватарах

**Drag-and-Drop для папок:**
- Перетаскивание папок для изменения порядка
- Папка "Все" не перетаскивается
- Визуальная обратная связь при перетаскивании
- Сохранение нового порядка

**Исключения уведомлений:**
- Модальное окно для управления исключениями
- Поиск чатов в модальном окне
- Добавление/удаление чатов из исключений
- Отображение количества исключений в подзаголовках

#### 3.5. Адаптивность

**Десктоп:**
- Двухколоночный layout: список чатов слева, окно чата справа
- Фиксированное субменю вверху
- Полная функциональность доступна

**Мобильные устройства:**
- Список чатов скрыт по умолчанию
- Кнопка меню (HamburgerMenuIcon) в субменю для открытия списка
- Полноэкранный модальный список чатов
- Автоматическое закрытие списка при выборе чата
- Оверлей для закрытия меню при клике вне его
