# Документация страницы: Telegram Чаты (telegram/chats/page.tsx)

## Общее описание

Страница списка чатов Telegram. Отображает все чаты из подключенного Telegram аккаунта, позволяет управлять чатами, просматривать переписку и настраивать чаты.

## Компоненты страницы

### 1. Навигационные вкладки
- **Компонент**: `Link` компоненты
- **Назначение**: Переключение между разделами Telegram
- **Вкладки**:
  - Вход
  - 2FA
  - Чаты (текущая страница, активна)
- **Логика**: 
  - Подсвечивает активную вкладку
  - При клике происходит переход на соответствующую страницу
- **Связи**: 
  - `/telegram` - страница входа
  - `/telegram/2fa` - страница 2FA

### 2. Субменю вверху страницы
- **Компонент**: `Flex` с кнопками
- **Назначение**: Быстрый доступ к настройкам (всегда доступно)
- **Пункты меню**:
  - Настройки аккаунта: настройки Telegram аккаунта
  - Папки: управление папками чатов
  - Настройки автоматизаций: настройка автоматизаций для чатов
- **Логика**: 
  - При клике на кнопку открывает/закрывает соответствующий раздел
  - Подсвечивает активный пункт меню
  - Отображает контент выбранного раздела в карточке под меню
- **Особенности**: Всегда доступно вверху страницы, как на странице `/recr-chat`

### 3. Список чатов
- **Компонент**: Список чатов
- **Назначение**: Отображение всех чатов Telegram
- **Логика**: 
  - Отображает список чатов с аватарами, названиями и превью сообщений
  - Показывает дату последнего сообщения
  - Показывает счетчик непрочитанных сообщений (Badge)
  - Кнопка настроек для каждого чата
  - При клике на чат открывает окно чата справа
  - Подсвечивает выбранный чат
- **Фильтрация**: 
  - Поиск по названию чата (в реальном времени)
  - Без учета регистра

### 4. Окно чата
- **Компонент**: Карточка с перепиской
- **Назначение**: Отображение и отправка сообщений в выбранном чате
- **Логика**: 
  - Отображается справа от списка чатов при выборе чата
  - Заголовок: название чата, аватар, кнопка настроек
  - Контейнер сообщений: отображение истории переписки
  - Поле ввода: отправка новых сообщений
  - Разные стили для сообщений пользователя и из Telegram
  - Автопрокрутка к новым сообщениям
- **Поведение**: 
  - Отображается только при выборе чата
  - При отсутствии выбранного чата показывает сообщение "Выберите чат"

### 5. Модальное окно настроек чата
- **Компонент**: `Dialog` из Radix UI
- **Назначение**: Настройки конкретного чата
- **Логика**: 
  - Открывается при клике на кнопку настроек чата
  - Показывает название чата в заголовке
  - Содержит настройки чата (TODO: реализовать)

## Состояние компонента

### State переменные:
- `selectedChatId`: ID выбранного чата (null если не выбран)
- `searchQuery`: поисковый запрос для фильтрации чатов
- `activeSubmenu`: активный пункт субменю ('account' | 'folders' | 'automation' | null)
- `chatSettingsOpen`: флаг открытия модального окна настроек чата
- `settingsChatId`: ID чата для настроек
- `message`: текст сообщения в поле ввода

## Функции и обработчики

### handleChatClick(chatId)
- **Назначение**: Выбор чата для просмотра
- **Логика**: 
  - Устанавливает `selectedChatId`
  - Открывает окно чата справа
  - Подсвечивает выбранный чат в списке
- **Поведение**: Вызывается при клике на чат в списке

### handleChatSettingsClick(chatId, e)
- **Назначение**: Открытие настроек чата
- **Логика**: 
  - Предотвращает всплытие события (stopPropagation)
  - Устанавливает `settingsChatId` и открывает модальное окно
- **Поведение**: Вызывается при клике на кнопку настроек чата

### handleSendMessage()
- **Назначение**: Отправка сообщения в выбранный чат
- **Логика**: 
  1. Проверяет наличие текста сообщения и выбранного чата
  2. Создает новое сообщение с текущим временем
  3. Добавляет сообщение в массив сообщений чата
  4. Обновляет превью и дату последнего сообщения
  5. Очищает поле ввода
- **TODO**: Реализовать отправку через Telegram API
- **Связи**: 
  - Telegram API: отправка сообщения на сервер Telegram

### filteredChats
- **Назначение**: Отфильтрованный список чатов
- **Логика**: 
  - Фильтрует чаты по поисковому запросу (название чата)
  - Без учета регистра
- **Используется**: Для отображения в списке чатов

### selectedChat
- **Назначение**: Выбранный чат для отображения
- **Логика**: 
  - Находит чат по `selectedChatId` в массиве `MOCK_CHATS`
  - Возвращает `undefined` если чат не выбран
- **Используется**: Для отображения в окне чата

## Моковые данные

### MOCK_CHATS
Массив объектов чатов Telegram с полями:
- `id`: уникальный идентификатор чата
- `name`: название чата
- `preview`: превью последнего сообщения
- `avatar`: символ для аватара (первая буква названия)
- `date`: дата/время последнего сообщения (форматированная строка)
- `unreadCount`: количество непрочитанных сообщений (опционально)
- `messages`: массив сообщений в чате (опционально)

**TODO**: Заменить на реальные данные из Telegram API

### TelegramMessage
Интерфейс сообщения в Telegram чате:
- `id`: уникальный идентификатор сообщения
- `text`: текст сообщения
- `timestamp`: время сообщения
- `sender`: отправитель ('user' - пользователь, 'telegram' - из Telegram)
- `senderName`: имя отправителя (для сообщений из Telegram, опционально)
