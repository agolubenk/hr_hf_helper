# Документация страницы: Запрещено (forbidden/page.tsx)

## Общее описание

Страница ошибки 403 (Forbidden). Отображается при отсутствии прав доступа к запрашиваемому ресурсу.

## Компоненты страницы

### 1. Сообщение об ошибке
- **Компонент**: `Text` с описанием
- **Назначение**: Информирование пользователя об ошибке
- **Логика**: 
  - Отображает код ошибки 403
  - Показывает сообщение "Доступ запрещен"
  - Описание проблемы

### 2. Кнопка возврата
- **Компонент**: `Button` с навигацией
- **Назначение**: Возврат на главную страницу
- **Логика**: 
  - При клике происходит переход на `/`
  - Позволяет пользователю вернуться в приложение
- **Связи**: Навигация на `/`
