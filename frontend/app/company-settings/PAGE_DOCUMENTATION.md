# Документация страницы: Настройки компании (company-settings/page.tsx)

## Общее описание

Главная страница настроек компании. Отображает общие настройки компании, включая логотип, офисы, календарь и базовые параметры.

## Компоненты страницы

### 1. GeneralSettings
- **Расположение**: `@/components/company-settings/GeneralSettings`
- **Назначение**: Компонент общих настроек компании
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Форма редактирования общих настроек компании
  - Логотип компании (загрузка и отображение)
  - Офисы и локации (добавление, редактирование, удаление)
  - Календарь (рабочие дни, праздники)
  - Базовые параметры компании (название, описание и т.д.)
- **Связи**: 
  - API: сохранение настроек через API
  - После сохранения обновляет данные компании

## Состояние компонента

### State переменные:
- Нет (все состояние управляется внутри `GeneralSettings`)

## Функции и обработчики

### В GeneralSettings:
- **Загрузка логотипа**: Загрузка файла изображения и отображение
- **Управление офисами**: Добавление, редактирование, удаление офисов
- **Управление календарем**: Настройка рабочих дней и праздников
- **Сохранение настроек**: Отправка данных на сервер через API

## Структура данных

### Настройки компании:
- **Логотип**: URL или файл изображения
- **Офисы**: массив объектов офисов с полями:
  - `id`: уникальный идентификатор
  - `name`: название офиса
  - `address`: адрес офиса
  - `city`: город
  - `country`: страна
- **Календарь**: 
  - Рабочие дни недели
  - Праздничные дни
- **Базовые параметры**:
  - Название компании
  - Описание
  - Контактная информация
