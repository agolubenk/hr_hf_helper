# Документация страницы: Интеграции (company-settings/integrations/page.tsx)

## Общее описание

Страница управления интеграциями компании. Позволяет настраивать интеграции с внешними сервисами (Huntflow, Google Calendar, и т.д.).

## Компоненты страницы

### 1. IntegrationsPage
- **Расположение**: `@/components/profile/IntegrationsPage`
- **Назначение**: Компонент настроек интеграций
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение списка доступных интеграций
  - Настройка параметров интеграций
  - Управление доступом интеграций
  - Подключение/отключение интеграций
- **Связи**: Используется для управления интеграциями

### 2. IntegrationSettingsForm
- **Расположение**: `@/components/profile/IntegrationSettingsForm`
- **Назначение**: Форма настройки конкретной интеграции
- **Пропсы**: 
  - `integration`: данные интеграции
  - `onSave`: обработчик сохранения
- **Логика**: 
  - Форма с полями настройки интеграции
  - Валидация обязательных полей
  - Сохранение через API
- **Связи**: Используется для настройки интеграций

### 3. IntegrationScopeModal
- **Расположение**: `@/components/company-settings/integrations/IntegrationScopeModal`
- **Назначение**: Модальное окно управления областью действия интеграции
- **Пропсы**: 
  - `isOpen`: флаг открытости
  - `onClose`: обработчик закрытия
  - `integration`: данные интеграции
  - `onSave`: обработчик сохранения области
- **Логика**: 
  - Управление областью действия интеграции
  - Выбор доступных разделов/функций
  - Сохранение через API
- **Связи**: Используется для настройки области действия интеграций

## Состояние компонента

### State переменные:
- `integrations`: массив всех интеграций
- `selectedIntegration`: выбранная интеграция для настройки
- `isScopeModalOpen`: флаг открытия модального окна области действия
