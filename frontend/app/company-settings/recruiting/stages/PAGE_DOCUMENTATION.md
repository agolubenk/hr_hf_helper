# Документация страницы: Этапы найма (company-settings/recruiting/stages/page.tsx)

## Общее описание

Страница управления этапами найма компании. Позволяет создавать, редактировать и удалять этапы найма, настраивать их порядок и параметры.

## Компоненты страницы

### 1. Список этапов
- **Компонент**: Таблица или список с возможностью переупорядочивания
- **Назначение**: Отображение всех этапов найма
- **Логика**: 
  - Отображает этапы в порядке их следования
  - Позволяет изменять порядок (drag & drop)
  - Кнопки редактирования и удаления

## Состояние компонента

### State переменные:
- `stages`: массив всех этапов найма
- `editingStage`: этап для редактирования
- `showAddForm`: флаг отображения формы добавления

## Функции и обработчики

### CRUD операции:
- **Создание**: Добавление нового этапа
- **Чтение**: Загрузка списка этапов
- **Обновление**: Редактирование существующего этапа
- **Удаление**: Удаление этапа с подтверждением
- **Переупорядочивание**: Изменение порядка этапов

## Моковые данные

### mockStages
Массив объектов этапов найма с полями:
- `id`: уникальный идентификатор
- `name`: название этапа (Заявка, Скрининг, Интервью, Оффер, Принят, Отказ)
- `order`: порядок следования
- `description`: описание этапа
- `parameters`: параметры этапа (SLA, длительность и т.д.)
