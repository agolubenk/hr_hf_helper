# Документация страницы: Вход (login/page.tsx)

## Общее описание

Страница входа в систему. Поддерживает два метода авторизации: email/пароль и Google OAuth, позволяет переключать тему и переходить на восстановление пароля.

## Компоненты страницы

### 1. FloatingLabelInput
- **Расположение**: `@/components/FloatingLabelInput`
- **Назначение**: Поле ввода с плавающей меткой
- **Пропсы**:
  - `label`: текст метки
  - `type`: тип поля ('text' | 'password' | 'email')
  - `value`: значение поля
  - `onChange`: обработчик изменения
  - `icon`: иконка (опционально)
- **Логика**: 
  - Метка перемещается вверх при фокусе или заполнении
  - Анимация перемещения метки
- **Используется**: Для полей email и password

### 2. Кнопка переключения темы
- **Компонент**: `Button` с иконкой
- **Назначение**: Переключение между светлой и темной темой
- **Логика**: 
  - Использует `useTheme().toggleTheme()`
  - Отображает `SunIcon` для темной темы, `MoonIcon` для светлой
- **Расположение**: 
  - Десктоп: справа от формы
  - Мобильные: в углу формы

## Состояние компонента

### State переменные:
- `email`: значение поля email
- `password`: значение поля password
- `isLoading`: флаг загрузки (показывает индикатор при отправке формы)

## Функции и обработчики

### handleEmailLogin(e)
- **Назначение**: Обработчик входа через email/пароль
- **Логика**: 
  1. Предотвращает стандартное поведение формы
  2. Устанавливает `isLoading = true`
  3. Отправляет данные авторизации на сервер
  4. При успехе сохраняет токен и редиректит на главную
  5. При ошибке показывает сообщение об ошибке

### handleGoogleLogin()

- Не использует `AppLayout` - имеет собственный layout
- Поддержка двух методов авторизации
- Переключение темы доступно на странице входа
- Адаптивная верстка (разные расположения кнопки темы для десктопа и мобильных)
