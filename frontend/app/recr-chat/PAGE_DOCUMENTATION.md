# Документация страницы: Чат рекрутера (recr-chat/page.tsx)

## Общее описание

Страница чата рекрутера с кандидатами. Централизованный интерфейс для общения со всеми кандидатами из разных мессенджеров (Telegram, WhatsApp, Viber), управления контактами и информацией о кандидатах.

## Компоненты страницы

### 1. WorkflowChat
- **Расположение**: `@/components/workflow/WorkflowChat`
- **Назначение**: Компонент чата с кандидатами
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: 
  - Отображение истории сообщений
  - Отправка сообщений
  - Обработка команд через теги
- **Связи**: Используется для общения с кандидатами

### 2. SlotsPanel
- **Расположение**: `@/components/workflow/SlotsPanel`
- **Назначение**: Панель свободных слотов для интервью
- **Пропсы**: Нет (использует внутреннее состояние)
- **Логика**: Отображение свободных слотов по неделям
- **Связи**: Используется для быстрого копирования доступного времени

### 3. Список кандидатов
- **Компонент**: Кастомный список с фильтрацией
- **Назначение**: Отображение списка всех кандидатов
- **Логика**: 
  - Поиск по имени кандидата
  - Фильтрация по статусу (просмотрен/непросмотрен)
  - Отображение непрочитанных сообщений
  - Отображение подозрений на дубликаты
- **Связи**: При клике на кандидата открывает чат с ним

### 4. Форма редактирования кандидата
- **Компонент**: Dialog с формой
- **Назначение**: Редактирование информации о кандидате
- **Логика**: 
  - Редактирование личных данных
  - Управление контактами (email, телефоны, мессенджеры, социальные сети)
  - Отметка как просмотренного
  - Управление подозрениями на дубликаты
- **Связи**: Открывается при клике на кнопку редактирования

## Состояние компонента

### State переменные:
- `selectedCandidate`: выбранный кандидат для чата
- `candidates`: массив всех кандидатов
- `searchQuery`: поисковый запрос
- `statusFilter`: фильтр по статусу (просмотрен/непросмотрен)
- `isEditModalOpen`: флаг открытия модального окна редактирования
- `editingCandidate`: кандидат для редактирования

## Функции и обработчики

### Фильтрация кандидатов
- **Логика**:
  1. Поиск: имя кандидата содержит `searchQuery` (без учета регистра)
  2. Статус: совпадает с `statusFilter` (или 'all')
- **Результат**: `filteredCandidates` - отфильтрованный массив кандидатов

### Управление контактами
- **Добавление контакта**: Добавление нового контакта (email, телефон, мессенджер, соцсеть)
- **Удаление контакта**: Удаление существующего контакта
- **Редактирование контакта**: Изменение данных существующего контакта

### Отметка как просмотренного

  - Переключает флаг `isViewed` кандидата

## Моковые данные

### mockCandidates
Массив объектов кандидатов с полями:
- `id`: уникальный идентификатор
- `name`: имя кандидата
- `avatar`: URL аватара (опционально)
- `isViewed`: флаг просмотренности
- `unreadCount`: количество непрочитанных сообщений
- `lastMessage`: последнее сообщение (опционально)
- `lastMessageTime`: время последнего сообщения
- `contacts`: массив контактов (email, телефоны, мессенджеры, соцсети)
- `isDuplicate`: флаг подозрения на дубликат
- `duplicateOf`: ID кандидата-дубликата (опционально)
