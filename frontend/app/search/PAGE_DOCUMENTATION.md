# Документация страницы: Поиск (search/page.tsx)

## Общее описание

Страница результатов глобального поиска по приложению. Отображает результаты поиска с возможностью фильтрации по областям (вакансии, кандидаты, компании).

## Компоненты страницы

### 1. Заголовок с запросом
- **Компонент**: `Text` с отображением запроса
- **Назначение**: Отображение текущего поискового запроса
- **Логика**: 
  - Показывает запрос из URL параметра `?q=`
  - Если запрос пустой - показывает сообщение
- **Связи**: Использует `searchParams.get('q')`

### 2. Кнопки переключения области поиска
- **Компонент**: `Button` компоненты
- **Назначение**: Переключение области поиска
- **Области**: 
  - Все данные
  - Вакансии
  - Кандидаты
  - Компании
- **Логика**: 
  - При клике обновляет URL параметр `?scope=`
  - Сохраняет поисковый запрос `?q=`
  - Подсвечивает активную область
- **Связи**: Использует `useRouter` для обновления URL

## Функции и обработчики

### setScope(scope)
- **Назначение**: Установка области поиска
- **Логика**: 
  - Обновляет URL параметр `?scope=` через `router.push()`
  - Сохраняет поисковый запрос `?q=` при обновлении
  - Не прокручивает страницу (scroll: false)
- **Поведение**: 
  - Вызывается при клике на кнопку области поиска
  - Обновляет URL для синхронизации и возможности делиться ссылками

## URL параметры

### ?q=QUERY
- **Тип**: Строка поискового запроса
- **Назначение**: Поисковый запрос для поиска
- **Пример**: `/search?q=react` ищет "react"
- **Обработка**: 
  - Читается через `useSearchParams()`
  - Отображается в заголовке страницы
  - Сохраняется при переключении области поиска

### ?scope=SCOPE
- **Тип**: Область поиска ('all' | 'vacancies' | 'candidates' | 'companies')
- **Назначение**: Фильтрация результатов по области
- **Пример**: `/search?q=react&scope=vacancies` ищет только в вакансиях
- **Обработка**: 
  - Читается через `useSearchParams()`
  - По умолчанию 'all' (все данные)
  - Обновляется при клике на кнопку области

## Области поиска

### Все данные (scope === 'all')
- **Назначение**: Поиск во всех данных приложения
- **Результаты**: Вакансии, кандидаты, компании

### Вакансии (scope === 'vacancies')
- **Назначение**: Поиск только в вакансиях
- **Результаты**: Только вакансии

### Кандидаты (scope === 'candidates')
- **Назначение**: Поиск только в кандидатах
- **Результаты**: Только кандидаты

### Компании (scope === 'companies')
- **Назначение**: Поиск только в компаниях
- **Результаты**: Только компании
