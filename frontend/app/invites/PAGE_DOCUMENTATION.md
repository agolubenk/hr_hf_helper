# Документация страницы: Инвайты (invites/page.tsx)

## Общее описание

Страница управления инвайтами на интервью. Позволяет создавать, просматривать, редактировать и удалять инвайты для кандидатов.

## Компоненты страницы

### 1. InvitesStats
- **Расположение**: `@/components/invites/InvitesStats`
- **Назначение**: Отображение статистики по инвайтам
- **Пропсы**:
  - `total`: общее количество инвайтов
  - `pending`: количество инвайтов со статусом "pending" (ожидают)
  - `sent`: количество инвайтов со статусом "sent" (отправлены)
  - `completed`: количество инвайтов со статусом "completed" (завершены)
- **Логика**: Отображает 4 карточки со статистикой, каждая с цветовой индикацией
- **Связи**: Получает данные из `MOCK_STATS` (TODO: заменить на API)

### 2. CreateInviteModal
- **Расположение**: `@/components/invites/CreateInviteModal`
- **Назначение**: Модальное окно создания нового инвайта
- **Пропсы**:
  - `isOpen`: флаг открытости модального окна
  - `onClose`: обработчик закрытия
  - `onSave`: обработчик сохранения (получает `{ combined_data: string }`)
- **Логика**: 
  - Поле ввода для комбинированных данных (ссылка на кандидата + дата-время)
  - Валидация обязательных полей
  - Отправка данных на сервер для создания инвайта
- **Связи**: 
  - API: `/google-oauth/invites/create/combined/` (TODO: раскомментировать)
  - После создания вызывает `loadInvites()` для обновления списка

### 3. Таблица инвайтов
- **Компонент**: `Table` из Radix UI
- **Назначение**: Отображение списка всех инвайтов
- **Колонки**:
  - Кандидат (кликабельно, переход на детальную страницу)
  - Вакансия
  - Дата интервью
  - Статус (с цветовой индикацией через Badge)
  - Создан (дата создания)
  - Действия (просмотр, редактирование, открыть Scorecard, копировать текст, удалить)
- **Логика**: 
  - Фильтрация по `searchQuery` и `statusFilter`
  - Пагинация (20 элементов на страницу)
  - Обработка пустого состояния

## Состояние компонента

### State переменные:
- `invites`: массив всех инвайтов (тип: `Invite[]`)
- `loading`: флаг загрузки данных
- `searchQuery`: поисковый запрос для фильтрации
- `statusFilter`: выбранный статус для фильтрации ('all' | 'pending' | 'sent' | 'completed' | 'cancelled')
- `page`: текущая страница пагинации (начинается с 1)
- `totalCount`: общее количество инвайтов
- `hasNext`: флаг наличия следующей страницы
- `hasPrevious`: флаг наличия предыдущей страницы
- `isCreateModalOpen`: флаг открытия модального окна создания

## Функции и обработчики

### loadInvites()
- **Назначение**: Загрузка списка инвайтов с учетом фильтров
- **Логика**:
  1. Устанавливает `loading = true`
  2. Фильтрует моковые данные по `searchQuery` (имя кандидата или вакансия)
  3. Фильтрует по `statusFilter` (если не 'all')
  4. Обновляет состояние
- **Вызывается**: 
  - При изменении `page` или `statusFilter` (useEffect)
  - При debounce поиска (через 500мс после ввода)
  - После удаления инвайта
  - После создания инвайта

### handleDelete(id)
- **Назначение**: Удаление инвайта
- **Логика**:
  1. Показывает confirm диалог для подтверждения
  2. Вызывает `invitesApi.delete(id)`
  3. При успехе показывает toast и обновляет список
- **Связи**: API `invitesApi.delete()`

### handleCopyInvitation(id)
- **Назначение**: Копирование текста инвайта в буфер обмена
- **Логика**:
  1. Получает текст инвайта через `invitesApi.getInvitationText(id)`
  2. Копирует в буфер обмена через `navigator.clipboard.writeText()`
  3. Показывает toast об успехе
- **Связи**: API `invitesApi.getInvitationText()`

### formatDate(dateString)
- **Назначение**: Форматирование даты для отображения
- **Логика**: Преобразует ISO строку в формат DD.MM.YYYY HH:MM
- **Используется**: Для отображения дат создания и времени интервью

## Фильтрация и поиск

### Поиск (searchQuery)
- **Поле**: TextField с иконкой поиска
- **Логика**: 
  - Ищет по имени кандидата (`candidate_name`) или названию вакансии (`vacancy_title`)
  - Без учета регистра
  - Debounce 500мс для уменьшения количества запросов
- **Поведение**: При вводе сбрасывает страницу на первую, если не на первой

### Фильтр по статусу (statusFilter)
- **Поле**: Select с опциями из `STATUS_OPTIONS`
- **Опции**: Все статусы, Ожидает, Отправлен, Завершен, Отменен
- **Логика**: Фильтрует инвайты по статусу
- **Цвета**: Определены в `STATUS_COLORS` для Badge

## Пагинация
