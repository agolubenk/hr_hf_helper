## Быстрая диагностика проблем

### Проблема: "Не получается подключиться к HH.ru API"
- [ ] Проверить интернет соединение
- [ ] Проверить URL API
- [ ] Проверить timeout
- [ ] Посмотреть логи ошибок

**Решение**:
```python
from apps.huntflow.hh_integration import HHResponsesHandler
handler = HHResponsesHandler(user)
try:
    result = handler.get_responses_from_hh("123")
except Exception as e:
    print(f"Error: {e}")
```

### Проблема: "Кандидаты не импортируются"
- [ ] Проверить фильтры
- [ ] Проверить, есть ли данные кандидатов
- [ ] Проверить Huntflow API ключ
- [ ] Посмотреть логи ошибок

**Решение**:
```python
# Проверить фильтры
responses = handler.get_responses_from_hh("123")
filtered, rejected = handler.hh_responses_filter.filter_responses(
    responses['items'], filters
)
print(f"Passed filter: {len(filtered)}")
print(f"Rejected: {rejected}")
```

### Проблема: "Синхронизация не запускается"
- [ ] Проверить, что Celery running
- [ ] Проверить, что Beat running
- [ ] Проверить schedule в celery config
- [ ] Посмотреть логи Celery

**Команда для проверки Celery**:
```bash
celery -A myproject inspect active
celery -A myproject inspect scheduled
```

### Проблема: "Высокий процент отклонения кандидатов"
- [ ] Проверить фильтры - может быть они слишком строгие
- [ ] Посмотреть статистику фильтрации
- [ ] Отрегулировать параметры фильтров
- [ ] Рассмотреть использование умных фильтров

**Анализ**:
```python
from apps.huntflow.models import HHFilterStatistics

stats = HHFilterStatistics.objects.get(configuration_id=123)
print(f"Rejection rate: {stats.rejection_rate}%")
print(f"Location: {stats.location_mismatch_percent}%")
print(f"Age: {stats.age_mismatch_percent}%")
print(f"Experience: {stats.experience_mismatch_percent}%")
```

## Метрики успеха

### После реализации вы должны иметь:

✅ **Получение откликов**
- Возможность получать отклики из HH.ru через API
- Сохранение откликов в БД
- История всех полученных откликов

✅ **Фильтрация**
- Работающие фильтры по локации, полу, возрасту, опыту
- Возможность сохранять конфигурации фильтров
- Статистика по причинам отклонения кандидатов

✅ **Импорт**
- Автоматический импорт прошедших фильтр кандидатов в Huntflow
- Связь с вакансиями в Huntflow

✅ **Автоматизация**
- Запланированная синхронизация по расписанию
- Обработка ошибок и повторные попытки
- Уведомления о результатах синхронизации

✅ **Мониторинг**
- Dashboard со статистикой импорта
- Логирование всех операций
