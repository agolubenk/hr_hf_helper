# 🎯 Функциональность замены плейсхолдеров в скоркардах

## 📋 Описание

Реализована функциональность автоматической замены плейсхолдеров `[HUNTFLOW_LINK]` и `[GRADE]` на реальные данные при создании и обновлении скоркардов.

## ✨ Возможности

### 🔗 Автоматическая замена плейсхолдеров

- **`[HUNTFLOW_LINK]`** - заменяется на реальную ссылку на кандидата в Huntflow
- **`[GRADE]`** - заменяется на реальный грейд кандидата
- **Комбинированные плейсхолдеры** - поддержка ячеек с несколькими тегами

### 📊 Источники данных

1. **Ссылка Huntflow** - генерируется из URL кандидата с учетом активной системы (prod/sandbox)
2. **Грейд кандидата** - берется из инвайте или получается из Huntflow API

## 🛠️ Техническая реализация

### Основные компоненты

1. **`ScorecardProcessor`** - основной класс для обработки скоркардов
2. **`GoogleSheetsService`** - расширен методами для поиска и замены в ячейках
3. **Интеграция с Huntflow API** - для получения реальных данных кандидатов

### Ключевые методы

```python
# Замена плейсхолдеров во всех ячейках
def find_and_replace_cells(spreadsheet_id, search_text, replace_text, sheet_name=None)

# Обновление конкретной ячейки
def update_cell_value(spreadsheet_id, sheet_name, cell_range, value)

# Получение ссылки Huntflow
def _get_huntflow_link(invite: Invite) -> str

# Получение грейда кандидата
def _get_candidate_grade(invite: Invite) -> str
```

## 📝 Инструкция по использованию

### Как добавить плейсхолдеры в скоркард

1. **Откройте шаблон скоркарда** в Google Sheets
2. **Добавьте плейсхолдеры** в нужные ячейки:
   - `[HUNTFLOW_LINK]` - для ссылки на кандидата в Huntflow
   - `[GRADE]` - для грейда кандидата
   - `[NAME]` - для имени кандидата
   - `[VACANCY_NAME]` - для названия вакансии
   - `[DATE]` - для даты интервью
   - `[INTERVIEW_TIME]` - для времени интервью

### Примеры использования

```
Ячейка A1: "Кандидат: [NAME]"
Ячейка B1: "Грейд: [GRADE]"  
Ячейка C1: "Ссылка: [HUNTFLOW_LINK]"
Ячейка D1: "Кандидат: [NAME], Грейд: [GRADE], Ссылка: [HUNTFLOW_LINK]"
```

### Автоматическая замена

Плейсхолдеры автоматически заменяются при:
- ✅ **Создании нового инвайта**
- ✅ **Обновлении скоркардов** через функцию массового обновления
- ✅ **Пересоздании скоркарда** для конкретного инвайта

## 🔧 Отладка

Если плейсхолдеры не заменяются:

1. **Проверьте наличие плейсхолдеров** в шаблоне скоркарда
2. **Убедитесь в корректности написания** (с квадратными скобками)
3. **Проверьте настройки Google OAuth** у пользователя
4. **Убедитесь в наличии данных** в Huntflow (ссылка на кандидата, грейд)
